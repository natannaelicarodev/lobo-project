# Etapa 01 --- Auditoria e base

## Objetivo

Entender o projeto real e garantir uma base Rojo organizada sem
implementar ainda o gameplay completo.

## Tarefas

1.  Inspecionar a raiz do repositório, os arquivos Luau, dependências e
    configuração Rojo.
2.  Identificar o que já existe e o que está funcional.
3.  Verificar como o projeto é sincronizado para Roblox Studio e quais
    testes são possíveis.
4.  Propor a menor alteração necessária para uma base previsível, sem
    reescrever partes válidas.
5.  Atualizar `STATUS.md` com arquitetura encontrada, comandos de
    execução, riscos e decisões.

## Restrições

-   Não crie ainda sistemas completos de clientes, economia ou polícia.
-   Não substitua o mapeamento Rojo sem uma razão concreta.
-   Não instale dependências sem verificar a necessidade.
-   Não declare que o Studio foi testado se ele não foi
    aberto/executado.

## Critérios de aceite

-   [ ] A estrutura existente está documentada.
-   [ ] A configuração Rojo foi entendida.
-   [ ] Há um procedimento claro para sincronizar o projeto.
-   [ ] As mudanças realizadas são pequenas e justificadas.
-   [ ] `STATUS.md` foi atualizado.

## Ao concluir

Pare e apresente o relatório definido em `CLAUDE.md`. Não avance para a
Etapa 02 automaticamente.
